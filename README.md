# 다음 장

하루의 계획과 실행, 읽고 배운 것을 기록하는 웹 서비스입니다.

[서비스 이용하기](https://next-chapter-steel-three.vercel.app)

## 만든 이유

하루에 무엇을 했는지, 계획을 지키지 못했다면 어떤 이유가 있었는지 돌아보고 싶어 만들었습니다.
책과 공부에서 얻은 생각도 함께 남기고, 약속한 사람과 각자 한 일을 확인할 수 있습니다.

## 주요 기능

- **하루 계획과 회고** — 할 일과 장단기 목표를 정하고, 실행 상태와 이유를 남깁니다. 회고는 자유롭게 작성합니다.

- **집중 기록** — 타이머를 사용하며 메모를 적고, 실제 집중한 시간을 기록합니다.

- **내 서재** — 책·영화·드라마를 보관하고 문장과 생각을 남깁니다. 다 읽은 책에는 완독 한줄평을 적을 수 있습니다.

- **학습 자료함** — 글과 강의 링크를 모으고 메모와 태그를 붙입니다. YouTube·Vimeo 영상은 다시 볼 구간을 저장할 수 있습니다.

- **메모와 검색** — 떠오른 내용을 짧게 적어두고 나중에 정리합니다. 전체 기록을 검색하거나 지난 글을 다시 읽으며 생각을 덧붙일 수 있습니다.

- **함께 확인** — 한 사람과 연결해 선택한 할 일과 사진을 공유합니다. 별도 게시물을 작성하지 않아도 서로의 진행 상황을 확인할 수 있습니다.

개인 기록은 기본적으로 비공개입니다. 함께 확인할 할 일과 사진의 공개 여부는 각각 직접 선택합니다.

## 사용 기술

- Next.js · React · TypeScript · Tailwind CSS
- Supabase — 인증, PostgreSQL, 파일 저장
- Vercel — 배포
